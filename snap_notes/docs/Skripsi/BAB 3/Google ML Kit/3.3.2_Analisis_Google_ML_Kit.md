# 3.3.2 Analisis Google ML Kit

## Paragraf Pengantar

Analisis Google ML Kit dilakukan untuk memahami kemampuan pustaka Text Recognition dalam mengenali teks serta tata letak informasi pada gambar struk belanja melalui koordinat piksel. Google ML Kit merupakan SDK dari Google yang menyediakan kemampuan Optical Character Recognition (OCR) berbasis machine learning, yang dalam penelitian ini berfungsi untuk mengubah gambar struk belanja menjadi teks terstruktur dengan informasi koordinat. Data teks per line yang dihasilkan kemudian diformat menjadi JSON payload untuk dikirim ke model Large Language Model (LLM) Gemini AI guna ekstraksi informasi transaksi yang lebih lanjut.

## Penjelasan Flowchart

**1. Pengguna mengunggah foto struk belanja**
Pengguna memilih gambar struk belanja dari galeri atau mengambil foto langsung menggunakan kamera perangkat. Citra ini menjadi input mentah yang akan diproses oleh sistem.

**2. Google ML Kit menerima input**
Sistem membuat objek `InputImage` dari file gambar dan menginisialisasi `TextRecognizer` dari Google ML Kit dengan konfigurasi bahasa Latin script untuk pengenalan teks Indonesia.

**3. Memproses input dengan Library Text Recognition**
Google ML Kit melakukan preprocessing internal meliputi normalisasi gambar, noise reduction, binarization, dan skew correction untuk meningkatkan kualitas input sebelum tahap recognition.

**4. Mengenali teks dan koordinat pada gambar**
Algoritma CNN (Convolutional Neural Network) melakukan text detection untuk mengidentifikasi region teks, kemudian OCR recognition mengkonversi region tersebut menjadi string teks beserta koordinat bounding box.

**5. Format raw text menjadi text per line**
Elemen teks individual dikelompokkan menjadi baris logis menggunakan algoritma berbasis geometri. Pengelompokan dilakukan berdasarkan koordinat Y yang serupa (threshold Δy), kemudian diurutkan berdasarkan koordinat X (kiri ke kanan).

**6. Menghasilkan objek kelas dengan atribut teks dan koordinat**
Hasil line segmentation dipetakan ke dalam objek terstruktur (`TextLineEntity`) yang memuat atribut: line number, text content, bounding box, corner points, dan confidence score. Objek ini diserialisasi menjadi format JSON untuk dikirim ke LLM Gemini AI.

**7. Aplikasi menampilkan teks dan koordinat boxline**
Aplikasi Flutter menampilkan hasil recognition kepada pengguna dengan menggambar bounding box (kotak pembatas) di atas gambar asli untuk memfasilitasi verifikasi visual.
